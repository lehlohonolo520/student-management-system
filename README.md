🎓 Student Management System (Java)

📖 Description

This is a simple console-based Student Management System built using Java.
The application allows users to manage student records by adding, viewing, and searching student information.

It demonstrates core programming concepts such as object-oriented programming (OOP), arrays (ArrayList), and user input handling.

---

✨ Features

- ➕ Add new students
- 📋 View all students
- 🔍 Search for a student by name
- 🚪 Exit the system

---

🛠️ Technologies Used

- Java
- ArrayList (Java Collections Framework)
- Scanner (User Input Handling)

---

⚙️ How to Run

1. Clone the repository

git clone https://github.com/your-username/student-management-system.git

2. Open the project

Open the project in any Java IDE like:

- IntelliJ IDEA
- Eclipse
- NetBeans

3. Compile and Run

javac StudentManagementSystem.java
java StudentManagementSystem

---

▶️ How It Works

1. The program displays a menu with options
2. Users can choose an option (1–4)
3. Based on the selection:
   - Add student details (name, age, course)
   - View all saved students
   - Search for a student by name
4. The system runs in a loop until the user exits
